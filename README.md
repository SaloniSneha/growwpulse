# 📊 Groww Weekly Review Pulse

> Turns recent Play Store reviews into a one-page weekly pulse — with themes, real user quotes, and action ideas — then emails it to you automatically.

---

## 🏗️ Architecture Overview

```
Phase 1 → Scrape      : google-play-scraper → data/reviews/YYYY-MM-DD.json
Phase 2a → Themes     : Groq LLM → 3-5 themes from review sample
Phase 2b → Classify   : Groq LLM → every review assigned to a theme
Phase 3 → Pulse Note  : Gemini LLM → one-page weekly note (MD + TXT)
Phase 4 → Email       : smtplib → multipart email (plain + HTML)
```

**Stack:** Python 3.11 · FastAPI · Next.js 14 · Groq (llama-3.3-70b) · Gemini 2.5 Flash · Gmail SMTP

## ⚙️ Environment Variables

Copy `.env.example` to `.env` and fill in your values:

```bash
cp .env.example .env
```

| Variable | Description | Where to get it |
|---|---|---|
| `GROQ_API_KEY` | Groq API key for Phase 2 | [console.groq.com](https://console.groq.com) |
| `GEMINI_API_KEY` | Gemini API key for Phase 3 | [aistudio.google.com](https://aistudio.google.com) |
| `EMAIL_SENDER` | Your Gmail address | Your Gmail |
| `EMAIL_PASSWORD` | Gmail App Password | [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) |
| `EMAIL_RECIPIENT` | Where to send the pulse | Your email |
| `GROQ_MODEL` | Groq model name | `llama-3.3-70b-versatile` |
| `GEMINI_MODEL` | Gemini model name | `gemini-2.5-flash` |

## 🚀 Quick Start (Local)

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Add your `.env` file

### 3. Run the full pipeline
```bash
# Full pipeline (all phases)
python -m groww_pulse.main --phase all --weeks 10

# Or phase by phase
python -m groww_pulse.main --phase scrape --weeks 10
python -m groww_pulse.main --phase analyze
python -m groww_pulse.main --phase classify
python -m groww_pulse.main --phase report
python -m groww_pulse.main --phase email --recipient you@example.com

# Send the email (not just dry-run)
python -m groww_pulse.main --phase all --send --recipient you@example.com
```

### 4. Start the web UI
```bash
# Terminal 1: Backend
uvicorn api:app --reload --port 8000

# Terminal 2: Frontend
cd web && npm install && npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

### 5. Run the scheduler (every 5 minutes locally)
```bash
python run_scheduler.py
```

## 🌐 Deployment

### Backend → Railway

1. Push repo to GitHub
2. Go to [railway.app](https://railway.app) → New Project → Deploy from GitHub
3. Select your repo
4. Railway auto-detects `Dockerfile`
5. Add environment variables in Railway dashboard (all vars from `.env`)
6. Add `PORT=8000`
7. Deploy → copy your Railway URL

### Frontend → Vercel

1. Go to [vercel.com](https://vercel.com) → New Project → Import from GitHub
2. Set **Root Directory** to `web`
3. Add environment variable: `NEXT_PUBLIC_API_URL=https://your-railway-url.up.railway.app`
4. Deploy

### GitHub Actions (Weekly Scheduler)

Add these secrets in your repo → Settings → Secrets → Actions:

| Secret | Value |
|---|---|
| `GROQ_API_KEY` | Your Groq key |
| `GEMINI_API_KEY` | Your Gemini key |
| `EMAIL_SENDER` | Your Gmail |
| `EMAIL_PASSWORD` | Gmail App Password |
| `SCHEDULER_RECIPIENT` | Recipient email |

The workflow runs every **Sunday at 3:35 PM IST** automatically.

## 🔁 How to Re-run for a New Week

```bash
# Run all phases fresh for this week
python -m groww_pulse.main --phase all --weeks 10 --send --recipient you@example.com

# Or with a specific date label
python -m groww_pulse.main --phase all --weeks 10 --date 2025-01-27 --send
```

Each run creates new timestamped files in `data/reviews/` and `data/reports/`.

## 🗂️ Theme Legend

Themes are auto-generated by the LLM each run. Common themes for Groww:

| Slug | Label | Typical Trigger |
|---|---|---|
| `app_performance` | App Performance & Crashes | Freeze, crash, slow, lag |
| `ui_ux` | UI/UX & Navigation | Confusing, can't find, layout |
| `investment_features` | Investment Features | SIP, mutual fund, stocks |
| `customer_support` | Customer Support | No response, KYC, ticket |
| `security_trust` | Security & Trust | OTP, login, verification |

Themes regenerate every run based on actual review content — they may differ week to week.

---

## 📧 Email Format

- **Subject:** `Groww Weekly Review Pulse -- Week of YYYY-MM-DD`
- **From:** Your configured `EMAIL_SENDER`
- **Body:** Multipart — plain text + HTML rendered from Markdown
- **Dry-run:** Saves `.eml` file to `data/reports/` without sending
